## Module Files

### Core Application

#### main.c (42,269 bytes)
**Purpose**: Application lifecycle, window management, UI initialization

**Key Responsibilities**:
- GTK application setup
- Window creation and configuration
- Header bar and menu construction
- Notebook (tab container) creation
- AI panel integration
- Global keyboard shortcut handling
- Widget lifecycle management

**Key Functions**:
- `activate()`: GTK application activation callback
- `on_key_press()`: Global keyboard event handler
- `on_toggle_ai_panel()`: AI panel visibility toggle
- `on_paned_realize()`: Dynamic panel width calculation

**Dependencies**: All other modules

---

### Terminal Emulation

#### terminal.c (21,634 bytes) / terminal.h (1,019 bytes)
**Purpose**: VTE terminal widget management

**Key Responsibilities**:
- Terminal widget creation and destruction
- Shell process spawning
- Split terminal operations (horizontal/vertical)
- Terminal focus management
- Command logging
- Copy/paste functionality

**Key Data Structures**:
```c
typedef struct {
    GtkWidget *box;           // Container
    GtkWidget *terminal;      // VTE widget
    GtkWidget *parent;        // Parent container
    gboolean is_split;        // Split state
    gboolean is_active;       // Focus state
} TerminalWidget;
```

**Key Functions**:
- `create_terminal_widget()`: Create new terminal
- `split_terminal_horizontal/vertical()`: Split operations
- `collapse_terminal()`: Collapse split
- `on_terminal_key_press()`: Command logging trigger

**Dependencies**: db.c (for logging), utils.c

---

### AI Integration

#### ai.c (17,537 bytes) / ai.h (1,413 bytes)
**Purpose**: AI API communication and response handling

**Key Responsibilities**:
- HTTP requests to Groq API via libsoup
- SSE (Server-Sent Events) streaming
- System prompt loading from Modelfile
- Response parsing and formatting
- Error handling

**Key Data Structures**:
```c
typedef struct {
    GtkEntry *entry;       // User input widget
    GtkWidget *webview;    // Response display widget
} AiWidgets;

typedef struct {
    GtkWidget *webview;
    GString *accumulated_response;
    GInputStream *stream;
} StreamData;
```

**Key Functions**:
- `send_ai_message()`: Initiate AI request
- `ai_stream_read_callback()`: Handle streaming chunks
- `get_system_prompt()`: Load Modelfile content
- `send_visualization_request()`: Diagram generation

**Dependencies**: webview_ai.c, conversation.c, libsoup-3.0

#### webview_ai.c (30,343 bytes) / webview_ai.h (913 bytes)
**Purpose**: WebView-based rich text rendering for AI responses

**Key Responsibilities**:
- WebKitGTK WebView creation and configuration
- Markdown-to-HTML conversion
- Mermaid.js diagram rendering
- JavaScript ↔ C bridge
- Theme synchronization

**Key Functions**:
- `create_ai_webview()`: Initialize WebView with HTML template
- `markdown_to_html()`: Convert markdown to HTML
- `webview_append_message()`: Add complete message
- `webview_start/update_ai_message()`: Streaming updates
- `webview_set_theme()`: Theme application

**Features**:
- Inline HTML/CSS/JS template
- Mermaid.js for diagrams
- Syntax highlighting for code blocks
- Collapsible thinking sections
- Auto-scrolling

**Dependencies**: None (standalone)

## Build Artifacts

### Generated Directories

#### bin/
Created by `make`, contains compiled executable.

**Contents**:
- `scythe-fixed`: Main application binary

**Cleanup**: `make clean` removes entire directory

#### obj/
Created by `make`, contains object files.

**Contents**: One `.o` file per `.c` source file

**Purpose**: Enables incremental compilation

**Cleanup**: `make clean` removes entire directory

### Runtime Generated

#### ~/.config/scythe/
User configuration directory.

**Contents**:
- `settings.json`: Application settings
- `scripts/`: User bash scripts

**Created**: Automatically on first run

#### ~/.local/share/scythe/
User data directory.

**Contents**:
- `sessions.db`: SQLite session log database
- `conversations/`: AI chat JSON files

**Created**: Automatically on first use

## Key Configuration Files

### Makefile
GNU Make build configuration.

**Key Variables**:
- `CC`: Compiler (gcc)
- `CFLAGS`: Compilation flags
- `LIBS`: Linker flags
- `SRC_DIR`, `OBJ_DIR`, `BIN_DIR`: Paths

**Targets**:
- `all` (default): Build application
- `clean`: Remove build artifacts
- `$(OBJ_DIR)/%.o`: Compile object files
- `$(BINARY)`: Link executable

### Modelfile
AI system prompt and instructions.

**Format**: Custom format inspired by Ollama Modelfile

**Sections**:
- `FROM`: Model identifier
- `SYSTEM """..."""`: System message
- Behavioral directives

**Usage**: Loaded by `get_system_prompt()` in `ai.c`
